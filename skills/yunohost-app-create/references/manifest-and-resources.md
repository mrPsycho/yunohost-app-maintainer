# YunoHost `manifest.toml` & `[resources]` Complete Reference (Packaging v2)

Sources: `doc.yunohost.org/en/dev/packaging/structure`, `manifest`, `resources`, `manifest.v2.schema.json`, and `package_linter`.

---

## 1. Repository File Structure (`<id>_ynh`)

```text
myapp_ynh/
├── manifest.toml                 # Package metadata, upstream, integration, install questions, resources
├── tests.toml                    # package_check CI test suite configuration
├── config_panel.toml             # Optional webadmin/CLI configuration panel (v1.0)
├── LICENSE                       # License of the YunoHost package wrapper (SPDX, e.g. MIT / AGPL-3.0)
├── README.md                     # Auto-generated by YunoHost/apps-tools readme_generator on YunoHost-Apps
├── .editorconfig                 # UTF-8, LF, 4-space indent, trim trailing whitespace
├── .gitattributes                # Linguist generated/language hints
├── scripts/
│   ├── _common.sh                # Shared variables & custom myynh_* functions
│   ├── install                   # Runs AFTER resources are provisioned
│   ├── upgrade                   # Runs AFTER safety backup & resource updates
│   ├── remove                    # Runs BEFORE resources are deprovisioned (runs WITHOUT set -eu)
│   ├── backup                    # Declarative ynh_backup calls + DB dumps to $YNH_CWD
│   ├── restore                   # Runs AFTER resources (except sources!) are re-provisioned
│   ├── change_url                # Relocates app to new $domain / $path
│   └── config                    # Optional custom getters/validators/setters/actions for config_panel.toml
├── conf/
│   ├── nginx.conf                # NGINX location template rendered by ynh_config_add_nginx
│   ├── systemd.service           # Optional systemd unit rendered by ynh_config_add_systemd
│   ├── extra_php-fpm.conf        # Optional extra directives appended by ynh_config_add_phpfpm
│   └── app.env / config.toml     # App config templates rendered by ynh_config_add
├── patches/
│   └── main/                     # Optional patches (*.patch) auto-applied with `patch -p1` by ynh_setup_source
├── hooks/
│   └── post_user_create          # Optional YunoHost event hooks (e.g. post_user_create, post_cert_update)
└── doc/
    ├── DESCRIPTION.md            # Mandatory extended catalog/info description (localized: DESCRIPTION_fr.md)
    ├── ADMIN.md                  # Optional post-install admin notes (supports __SETTING__ placeholders)
    ├── PRE_INSTALL.md            # Optional pre-install prompt/warning
    ├── POST_INSTALL.md           # Optional post-install popup & dismissible note (supports __SETTING__)
    ├── PRE_UPGRADE.md            # Optional pre-upgrade notice shown on every upgrade
    ├── PRE_UPGRADE.d/            # Optional version-gated pre-upgrade notices (<version>.md)
    ├── POST_UPGRADE.md           # Optional post-upgrade notice
    ├── POST_UPGRADE.d/           # Optional version-gated post-upgrade notices (<version>.md)
    └── screenshots/              # .png/.jpg/.webp screenshots (< 512 KB recommended, < 1024 KB max)
```

## 2. Top-Level `manifest.toml` Specification

All **10** top-level keys are **required** (`additionalProperties = false`; only optional top-level key is `antifeatures`):
`packaging_format`, `id`, `name`, `description`, `version`, `maintainers`, `upstream`, `integration`, `install`, `resources`.

```toml
#:schema https://raw.githubusercontent.com/YunoHost/apps/main/schemas/manifest.v2.schema.json

packaging_format = 2

id = "myapp"
name = "My App"
description.en = "Concise 10-15 word summary explaining what the app does"
description.fr = "Résumé concis en 10-15 mots expliquant ce que fait l'application"

version = "1.2.3~ynh1"

maintainers = ["your_handle"]
```

### Top-Level Constraints & `package_linter` Rules
- `packaging_format`: Must be integer `2`.
- `id`: Lowercase alphanumeric with `-` or `_` (`^[a-z0-9]((_|-)?[a-z0-9])+$`). **Never** end `id` with `_ynh`. Multi-instance installs set `$app` to `myapp`, `myapp__2`, `myapp__3`, etc.
- `name`: Display name, **maximum 22 characters** (`package_linter` errors at `> 22` chars).
- `description`: String or `{ en = "...", <xx> = "..." }` (2-letter lowercase ISO language codes only). Length `5..150` chars. **Forbidden**: containing `"for YunoHost"` (Error) or starting with `id`/`name` (Warning).
- `version`: Must match `^[0-9a-z]*([\.+-][0-9a-z]*)*~ynh[0-9]*$` (**lowercase only!** e.g. `1.2.3~ynh1`, `2.0.0+dfsg~ynh2`). Increment `~ynhN` for packaging-only updates.
- `maintainers`: **Must be an array of strings** (`["alice", "bob"]` or `[]`), never a bare string or comma-joined `["alice, bob"]`.

## 3. `[upstream]` Section (Required)

Only `license` is required. **Omit** optional keys that do not exist upstream (do not put `example.com`, `yunohost.org`, or duplicate `code` into `website`/`admindoc`/`userdoc`).

```toml
[upstream]
license = "MIT"
# license_url = "https://..." # Mandatory ONLY if license uses "LicenseRef-..."
website = "https://myapp.org"
demo = "https://demo.myapp.org"
admindoc = "https://docs.myapp.org/admin"
userdoc = "https://docs.myapp.org/user"
code = "https://github.com/org/myapp"
cpe = "cpe:2.3:a:org:myapp"
fund = "https://liberapay.com/myapp"
```

- `license`: Valid [SPDX identifier](https://spdx.org/licenses/) (or `LicenseRef-<Name>` paired with `license_url`).
- `cpe`: Matches `^cpe:2\.3:a:[a-zA-Z0-9_-]*:[a-zA-Z0-9_-]*$` (omit version segment).

## 4. `[integration]` Section (Required)

Required keys: `yunohost`, `architectures`, `multi_instance`, `ldap`, `sso`. (`package_linter` also checks `disk`, `ram.build`, `ram.runtime`, and `helpers_version = "2.1"`.)

```toml
[integration]
yunohost = ">= 12.1.38"
helpers_version = "2.1"
architectures = "all"          # Or subset of ["amd64", "arm64", "armhf", "i386"]
multi_instance = true
ldap = false                   # true | false | "not_relevant"
sso = false                    # true | false | "not_relevant"
disk = "100M"
ram.build = "500M"
ram.runtime = "150M"
```

- **`yunohost`**: Use `">= 12.1.38"` when using modern NGINX `proxy_params_no_auth` / `proxy_params_with_auth` / `fastcgi_params_*` includes (minimum non-deprecated baseline: `">= 12.1.17"`).
- **`ldap` vs `sso`**:
  - `ldap = true`: Users can log in with YunoHost credentials via LDAP (`dc=yunohost,dc=org` must appear in repo configs/scripts or `package_linter` warns!).
  - `sso = true`: Users logged into YunoHost's SSOwat portal are **automatically logged in** (must pair with `proxy_params_with_auth` / `fastcgi_params_with_auth` in `conf/nginx.conf`).
  - Use `"not_relevant"` **only** when the app has no concept of user accounts at all.
- **`byte_size` format** (`disk`, `ram.build`, `ram.runtime`): Regex `^[0-9]*(\.[0-9]*)?[kKmMgG]$` — write `"50M"`, `"1.5G"`, `"512K"`, **NEVER** `"50MB"` or `"1GB"`.

## 6. `[install]` Questions Section (Required; May Be Empty `[install]`)

Question IDs must match `^[a-z][a-z0-9_]*$`. Answers are automatically saved to `/etc/yunohost/apps/$app/settings.yml` and loaded as `$<question_id>` in all scripts — **EXCEPT**:
1. `init_<perm>_permission` (initializes SSOwat permission, not saved as setting).
2. `type = "password"` (passed as `$<question_id>` **only during `scripts/install`**, NEVER saved in `settings.yml`!).

```toml
[install]
    [install.domain]
    type = "domain"

    [install.path]
    type = "path"
    default = "/myapp"

    [install.init_main_permission]
    type = "group"
    default = "visitors" # "visitors" = public, "all_users" = private to YunoHost users

    [install.admin]
    type = "user"

    [install.password]
    type = "password"
    help.en = "Administrator password for the initial setup"
```

### Crucial `[install]` Rules
- **NEVER set `ask`** on core-handled generic questions: `("domain", "domain")`, `("path", "path")`, `("admin", "user")`, `("password", "password")`, `("init_main_permission", "group")`. YunoHost translates them automatically (`package_linter` warns if `ask` is set!).
- **ALWAYS set `ask.en`** on any custom question.
- **Root-only apps**: If the upstream app cannot run under a subpath (`/subpath`), **omit `[install.path]` completely** (YunoHost sets `$path` to `"/"`).
- **21 Valid `type` values**: `string`, `text`, `select`, `tags`, `email`, `url`, `date`, `time`, `color`, `password`, `path`, `boolean`, `domain`, `user`, `group`, `number`, `range`, `alert`, `markdown`, `file`, `app`.
- **`choices` gotcha**: Either `["fr", "en"]` OR `choices.opt_a = "Option A"`. Object keys must match `^[a-zA-Z][a-zA-Z0-9_]*$` (**no hyphens `-`**!) and values must be plain strings (not `.en`/`.fr` sub-tables).
- **`pattern` gotcha**: Use single quotes in TOML for regexes: `pattern.regexp = '^[a-z0-9_]+$'`, `pattern.error = "..."`.

## 7. Complete `[resources]` Reference (All 12 Resource Types)

### Resource Provisioning Lifecycle
- **`install`**: Provisioned **before** `scripts/install`.
- **`upgrade`**: Safety backup runs first; added/modified/removed resources are updated **before** `scripts/upgrade`.
- **`remove`**: `scripts/remove` runs **first**; resources are deprovisioned **after** `scripts/remove` (`data_dir` is deleted **only** with `--purge`).
- **`restore`**: Provisioned **before** `scripts/restore` — **EXCEPT `sources`**, which are NOT prefetched on `restore` (restore `$install_dir` from backup!).

> **Ordering Rule (`package_linter`)**: Whenever `[resources.database]` is used, `[resources.apt]` **MUST appear before** `[resources.database]` in `manifest.toml` and explicitly include `mariadb-server` (for `mysql`) or `postgresql` (for `postgresql`).

### 7.1 `sources` (`[resources.sources.<source_id>]`)
`<source_id>` matches `^[a-z0-9][a-z0-9_-]*$` (default `main`). Deployed in scripts via `ynh_setup_source --dest_dir="$install_dir" [--source_id="..."]`.

```toml
[resources.sources.main]
url = "https://github.com/org/myapp/archive/refs/tags/v1.2.3.tar.gz"
sha256 = "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
autoupdate.strategy = "latest_github_tag"

# Multi-arch binary example:
[resources.sources.server]
in_subdir = false
amd64.url = "https://github.com/org/myapp/releases/download/v1.2.3/myapp-linux-amd64.tar.gz"
amd64.sha256 = "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
arm64.url = "https://github.com/org/myapp/releases/download/v1.2.3/myapp-linux-arm64.tar.gz"
arm64.sha256 = "fedcba9876543210fedcba9876543210fedcba9876543210fedcba9876543210"
autoupdate.strategy = "latest_github_release"
autoupdate.asset.amd64 = "^myapp-linux-amd64\\.tar\\.gz$"
autoupdate.asset.arm64 = "^myapp-linux-arm64\\.tar\\.gz$"

# Single unextracted file / binary / .deb:
[resources.sources.cli]
url = "https://example.org/myapp-cli"
sha256 = "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
format = "whatever"
extract = false
rename = "myapp-cli"
```
- Valid `format` enum: `"tar.bz2"`, `"tar.gz"`, `"tar.xz"`, `"tar.zst"`, `"xz"`, `"zip"`, `"zst"`, `"docker"`, `"whatever"` (**NEVER** `"script"`!).
- `in_subdir`: `true` (default, strips 1 top folder), `false` (0 folders), or integer `N` (strips `N` nested folders).
- `prefetch`: `true` (default) or `false`.

### 7.2 `system_user` (`[resources.system_user]`)
Creates Unix user & group `$app`.
- Optional: `allow_ssh = false`, `allow_sftp = false`, `allow_email = false` (when `true`, configures local Postfix auth and sets `$mail_pwd` / `__MAIL_PWD__`), `home = "/var/www/__APP__"` (only `__APP__` placeholder works in `home`!).

### 7.3 `install_dir` (`[resources.install_dir]`)
Creates `/var/www/$app` (sets `$install_dir` / `__INSTALL_DIR__`). Wiped on `remove`.
- Optional: `dir = "/var/www/__APP__"` (avoid `/opt/yunohost`), `owner = "__APP__:rwx"`, `group = "__APP__:rx"` (or `"www-data:rx"` for static/PHP webapps). Permissions apply to top dir only (non-recursive).

### 7.4 `data_dir` (`[resources.data_dir]`)
Creates `/home/yunohost.app/$app` (sets `$data_dir` / `__DATA_DIR__`). Deleted **only** on `yunohost app remove --purge`.
- Optional: `dir = "/home/yunohost.app/__APP__"`, `subdirs = ["uploads", "storage"]`, `owner = "__APP__:rwx"`, `group = "__APP__:rx"`.

### 7.5 `permissions` (`[resources.permissions.<perm>]`)
`<perm>` must be **>= 2 chars** (`^.[a-z][a-z0-9_]*$`, no hyphens).
```toml
[resources.permissions]
main.url = "/"

api.url = "/api"
api.show_tile = false
api.allowed = "visitors"
api.auth_header = false        # Disable SSOwat Authorization header injection on API routes!

admin.url = "/admin"
admin.label = "Admin"
admin.show_tile = false
admin.allowed = "admins"
admin.protected = false
admin.additional_urls = ["/metrics"]
```
*(Regex URLs supported via `re:^/api/v[0-9]+/.*$`. If `main.url` is set, either `[install.init_main_permission]` or `main.allowed` must exist.)*

### 7.6 `ports` (`[resources.ports.<port_name>]`)
`<port_name>` must be **>= 2 chars** (`^.[a-z][a-z0-9_]*$`, no hyphens).
- `[resources.ports]` (empty) or `main.default = 8080` -> sets `$port` (`__PORT__`).
- `turn.default = 5349` -> sets `$port_turn` (`__PORT_TURN__`).
- Optional: `exposed = "TCP" | "UDP" | "Both" | true | false` (default `false`; **NEVER** set `exposed` on internal HTTP ports behind NGINX or YunoHost Diagnosis will report a port failure!), `fixed = true | false`.

### 7.7 `apt` (`[resources.apt]`)
Creates virtual meta-package `${app//_/-}-ynh-deps`.
```toml
[resources.apt]
packages = [
    "mariadb-server",
    "php8.3-fpm",
    "php8.3-cli",
    "php8.3-mysql",
    "php8.3-mbstring",
]
packages_from_raw_bash = """
if [ "$YNH_ARCH" = "amd64" ]; then
    echo "intel-media-va-driver"
fi
"""
extras.custom_repo.repo = "deb https://repo.example.org/debian bookworm main"
extras.custom_repo.key = "https://repo.example.org/pubkey.gpg"
extras.custom_repo.packages = ["custom-pkg"]
```
- Including `php8.3-*` automatically sets `$php_version` (`"8.3"`, `__PHP_VERSION__`). Never use `php7.4-*` (Error), `php8.0`/`8.1` (Warning), or unversioned `php-foo`.

### 7.8 `database` (`[resources.database]`)
```toml
[resources.database]
type = "mysql" # "mysql" | "postgresql"
```
Auto-creates DB + user (`$db_name`, `$db_user`, `$db_pwd` / `__DB_NAME__`, `__DB_USER__`, `__DB_PWD__`). Only 1 database per app via `[resources.database]`.

### 7.9 Language & Tooling Resources (`nodejs`, `ruby`, `go`, `composer`)
```toml
[resources.nodejs]
version = "22"        # Sets $nodejs_version, $nodejs_dir, $path_with_nodejs; adds node/npm/corepack to $PATH

[resources.ruby]
version = "3.3"       # Sets $ruby_version, $ruby_dir, $path_with_ruby; REQUIRES apt build deps:
                      # gcc, make, libjemalloc-dev, libffi-dev, libyaml-dev, zlib1g-dev

[resources.go]
version = "1.23"      # Sets $go_version, $go_dir, $path_with_go; adds go to $PATH

[resources.composer]
version = "2.8"       # Downloads $install_dir/composer.phar (requires install_dir + php in apt); run via ynh_composer_exec
```
*(Note: There is NO `[resources.python]` or `[resources.rust]`. For Python, put `python3`, `python3-venv`, `python3-pip` in `[resources.apt]` and create `"$install_dir/venv"`.)*

## 8. Auto-Injected Variables & Placeholders Summary

| Source | Bash Variable in `scripts/*` | Template Token (`ynh_config_add`) |
|---|---|---|
| Core | `$app`, `$YNH_ARCH`, `$YNH_DEBIAN_VERSION`, `$YNH_APP_BASEDIR` | `__APP__` |
| `[install.<q>]` | `$<q>` (`$domain`, `$path`, `$admin`, ...) | `__<Q>__` (`__DOMAIN__`, `__PATH__`, `__ADMIN__`) |
| `change_url` | `$old_domain`, `$new_domain`, `$change_domain`, `$old_path`, `$new_path`, `$change_path` | `__DOMAIN__`, `__PATH__` |
| `install_dir` / `data_dir` | `$install_dir`, `$data_dir` | `__INSTALL_DIR__`, `__DATA_DIR__` |
| `ports` | `$port` (`main`), `$port_<name>` | `__PORT__`, `__PORT_<NAME>__` |
| `apt` (`phpX.Y-*`) | `$php_version` | `__PHP_VERSION__` |
| `database` | `$db_name`, `$db_user`, `$db_pwd` | `__DB_NAME__`, `__DB_USER__`, `__DB_PWD__` |
| `system_user` (`allow_email`) | `$mail_pwd` | `__MAIL_PWD__` |
| `nodejs` | `$nodejs_version`, `$nodejs_dir`, `$path_with_nodejs` | `__NODEJS_VERSION__`, `__NODEJS_DIR__`, `__PATH_WITH_NODEJS__` |
| `ruby` | `$ruby_version`, `$ruby_dir`, `$path_with_ruby` | `__RUBY_VERSION__`, `__RUBY_DIR__`, `__PATH_WITH_RUBY__` |
